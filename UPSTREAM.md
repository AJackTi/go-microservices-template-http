# Upstream and attribution

This repository contains code that substantially matches the public course
source in [tsawler/go-micro](https://github.com/tsawler/go-micro), published
for Trevor Sawler's “Working with Microservices in Go” course.

The earliest local commit already contains GoCode.ca templates, but the local
history does not record whether the code was cloned, downloaded, or recreated
while following the course. To preserve the upstream rights regardless of that
unknown acquisition path, this repository retains Trevor Sawler's 2022 MIT
copyright notice in [LICENSE.md](LICENSE.md).

The upstream baseline inspected for this attribution was commit
92f61983260d9d916632f4f896134b3932b4601e.

Subsequent changes in this repository are maintained by its contributors.
